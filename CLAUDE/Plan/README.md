folder (e.g. `00001-feature-name/`) with a `PLAN.md` file.

## Plan Numbering

- Plans use 5-digit zero-padded sequential numbers: `00001-`, `00002-`, etc.
- Use kebab-case for folder names: `00001-add-authentication/`
