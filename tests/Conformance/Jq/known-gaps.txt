# Format (shared with the shell conformance runner): UTF-8 text, blank lines and lines starting
# with # are ignored. Every other line is <glob><TAB><reason>, separated by a single tab. The glob
# uses fnmatch semantics (* ? [..]) and is matched against the case id; the first matching entry

# runner and are ignored by the PHP report.
#
# A case that fails and matches an entry is an expected failure. A case that fails without an entry,
# or passes while matching an entry, makes the report fail. An entry matching no case is reported
# as a stale-gap warning.
#
# Each entry names one case: a whole-file glob would also hide a new case added to that file.
